Free Hosting & Free Custom Domain Setup

Standalone Client Architecture

Because this application runs entirely client-side using native Web Crypto API, MediaDevices, and WebRTC, it does not require a paid back-end server to host. It can be hosted 100% free forever.

Method 1: GitHub Pages (100% Free)
yourname.github.io
  1. Create a free account on github.com.
  2. Create a new public repository named secure-chat.
  3. Upload this file as index.html.
  4. Go to Settings > Pages > Branch: main > Save.
  5. Your HTTPS website is live at https://<username>.github.io/secure-chat/.
Method 2: Vercel or Netlify Drag & Drop
app.vercel.app
  1. Visit vercel.com or netlify.com (Free Hobby Tier).
  2. Drag & drop a folder containing index.html.
  3. Instantly obtain a free secure HTTPS URL (WebRTC requires HTTPS to access camera & mic).
